每个参数最多 16×16 个等距采样点，三图按 A、B、A−B 排列；A/B 共用对称色阶，差值独立色阶。蓝=负、灰=零、红=正。每参数模式不能跨参数比较颜色大小；悬停查看色阶与参数名，点击进入大图。缺失或形状不一致明确标记，不作为零差异。超级紧凑模式仅保留模块标题，小图无间隙平铺；斜纹表示无可用数据。

这些状态值得看什么？

状态用途与展示
Adam m / vm 是梯度的一阶指数平均，v 是梯度平方的指数平均。展示抽样 RMS、最大绝对值、零值比例和异常值；不是当前梯度。
Master Parameters如有独立保存，显示其精度与统计；FP32 权重或动量本身不能证明存在 Master Parameters。
Optimizer step / LR Scheduler查看参数组学习率、betas、eps、weight decay、更新计数及调度器 last_epoch / _step_count。调度计数不一定等于训练 completed step。
RNG / DataLoader查看每个 rank 的状态文件、张量形状和数据游标等恢复信息。不把随机数状态画成网络热图，也不能仅凭文件存在保证完全复现。
epoch / completed step优先显示 resume_meta.json 中明确记录的进度，不从目录名称推断。

数值统计最多等距抽样 1024 点。仅受限读取 PyTorch 状态；大于 512 MiB 的文件只显示文件信息，DCP 分片仅展示存在情况。未读取、未发现与零值严格区分。
